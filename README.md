# QuickFix – Vehicle Service Booking Platform

QuickFix is a full-stack web application that helps vehicle owners find nearby garages and request vehicle repair services. It also allows garage owners to manage service requests and update the status of repairs.

I developed this project to make finding and booking vehicle services easier for customers while helping garages manage their work online.

## Features

### Customer
- Register and log in.
- Find nearby garages using location.
- Request vehicle repair services.
- View service request status.
- Access service and invoice details.

### Garage Owner
- Register and log in as a garage owner.
- View incoming service requests.
- Accept service requests.
- View customer and service request details.
- Update repair status.
- Manage garage information.

## Technologies Used

- **Frontend:** React.js
- **Backend:** Python, FastAPI
- **Database:** MongoDB
- **API Requests:** Axios
- **Version Control:** Git and GitHub

Through this project, I gained practical experience in React development, building APIs with FastAPI, working with MongoDB, and connecting frontend components with backend services.
